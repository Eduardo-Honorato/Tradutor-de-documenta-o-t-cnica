# Termos de Glossário

Este arquivo contém termos técnicos frequentes na documentação deste projeto.

## Deploy

O **deploy** é o processo de publicar novas versões do aplicativo para produção. Inclui etapas de build, teste e liberação dos artefatos.

## Endpoint

Um **endpoint** é um ponto de extremidade de API que aceita requisições e retorna respostas. Exemplos: `/api/v1/users`, `/health`.

## Pull Request

Um **pull request** (PR) é uma solicitação de contribuição de código no Git/GitHub. Permite que alterações sejam propostas e revisadas antes de serem mescladas na branch principal.

## Token

Um **token** é um identificador único usado para autenticação e autorização em APIs. Pode ser um JWT, token de sessão ou chave de API.

## Rollback

O **rollback** é a operação de reverter para uma versão anterior do sistema, geralmente após detectar um problema na versão atual.

## Framework

Um **framework** é uma estrutura de software que fornece funcionalidades comuns e padrões para desenvolvimento de aplicações, reduzindo a necessidade de código repetitivo. Exemplos: React, Django, Express.
