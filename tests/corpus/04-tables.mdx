# Tabelas

| Nome | Tipo | Descrição |
|------|------|-----------|
| `string` | texto | Um valor de texto |
| `number` | numérico | Um valor numérico |
| `boolean` | lógica | Verdadeiro ou falso |

## Tabela com alinhamento

| Esquerda | Central | Direita |
|:---------|:------:|--------:|
| `item1` | `item2` | `item3` |

## Código dentro de células

| Comando | Resultado |
|---------|-----------|
| `npm install` | Instala pacotes |
| `npm run build` | Constrói o projeto |

## Pipe escapado

Use \| para exibir um pipe literal em vez de criar uma nova coluna.
