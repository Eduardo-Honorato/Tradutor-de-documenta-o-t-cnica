# Quick Start

Welcome to the guide. Install the package with `npm install my-lib` and then run the `init` command.

## Installation

Follow these steps:

1. Install the dependencies.
2. Create a configuration file named `config.json`.
3. Start the server.

```bash
npm install my-lib
npx my-lib init
```

For more details, see the [API reference](https://example.com/api) page.

> **Note:** The default port is `3000`.
