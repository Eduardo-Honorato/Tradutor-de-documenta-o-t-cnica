# Configuration Guide

You can configure the library with a `config.json` file in the root of your project.

## Options

| Option | Description | Default |
| ------ | ----------- | ------- |
| `port` | The port used by the server. | `3000` |
| `debug` | Enables verbose logging. | `false` |

:::tip
Use the `--verbose` flag to see more details.
:::
